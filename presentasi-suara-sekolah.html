Presentasi Proyek

Suara Sekolah

Sistem portal laporan dan manajemen siswa berbasis web untuk memudahkan siswa mengirim laporan, serta membantu admin memantau, mengelola, dan menindaklanjuti laporan secara cepat dan terstruktur.

Ringkasan singkat

Proyek ini dibangun dengan Laravel dan MySQL untuk menyediakan portal akses siswa dan admin, dashboard statistik, manajemen siswa, serta fitur export laporan. Aplikasi ini juga dirancang agar dapat diakses dari perangkat mobile melalui jaringan lokal.

Focus utama

Login Dashboard Laporan Pengelolaan

2. Latar Belakang

Mengapa proyek ini dibuat?

Sekolah membutuhkan media yang cepat, rapi, dan mudah diakses untuk menerima laporan dari siswa. Proses pelaporan yang masih dilakukan secara manual sering kali kurang terstruktur, sulit dilacak, dan tidak efisien untuk dipantau oleh admin.

Masalah awal

  • Pelaporan masih bersifat manual dan tidak terorganisir.
  • Admin kesulitan memantau seluruh laporan dengan cepat.
  • Siswa butuh portal mudah diakses dari ponsel.

Solusi yang dibuat

  • Menyediakan portal laporan digital berbasis web.
  • Memberikan dashboard untuk admin agar data lebih mudah dipantau.
  • Menggunakan login berbasis nomor handphone untuk kecepatan akses.

3. Tujuan Proyek

Apa yang ingin dicapai?

  • Memudahkan siswa mengirim aspirasi, pengaduan, atau laporan barang hilang.
  • Memudahkan admin dalam memantau status laporan secara real-time.
  • Menyediakan dashboard statistik agar evaluasi lebih cepat dan akurat.
  • Membuat sistem login yang sederhana dengan nomor handphone dan password.
  • Memberikan manajemen data siswa yang lebih rapi dan mudah dikelola.

4. Fitur Utama

Fitur yang sudah tersedia

Login & Registrasi

Portal login terpisah untuk siswa dan admin, serta registrasi menggunakan nomor handphone tanpa email.

Dashboard Admin

Menampilkan statistik laporan, ringkasan jenis laporan, pencarian, dan pengaturan status.

Dashboard Siswa

Siswa dapat melihat riwayat laporan, detail laporan, dan mengedit laporan milik sendiri.

Manajemen Siswa

Admin dapat menambah, mengedit, mencari, mengurutkan, dan menghapus data siswa.

Export Data

Data laporan dapat diekspor ke format CSV sebagai arsip dan laporan eksternal.

Akses Mobile

Project dapat diakses melalui alamat IP lokal dari perangkat lain di jaringan yang sama.

5. Alur Sistem

Bagaimana aplikasi bekerja?

Alur siswa

  • Masuk ke portal login
  • Login dengan nomor handphone dan password
  • Membuat laporan
  • Melihat status dan riwayat laporan

Alur admin

  • Login ke portal admin
  • Melihat dashboard dan statistik
  • Mengubah status laporan
  • Kelola siswa dan export data

6. Struktur Teknologi

Teknologi yang digunakan

Backend

Laravel 12 untuk routing, controller, autentikasi, dan logika aplikasi.

Database

MySQL untuk menyimpan data siswa, laporan, sesi login, dan riwayat aktivitas.

Frontend

Blade + CSS custom untuk tampilan modern yang ramah digunakan di desktop maupun mobile.

Eksekusi

PHP Artisan, migrasi database, dan akses lokal melalui IP jaringan.

9. Dashboard Admin

Apa yang dilihat admin?

  • Total jumlah laporan masuk
  • Jumlah laporan hari ini
  • Jumlah laporan anonim dan selesai
  • Ringkasan per jenis laporan (aspirasi, pengaduan, barang hilang)
  • Tabel laporan dengan filter dan sorting
  • Fitur update status langsung dari daftar laporan

Dashboard ini dirancang agar admin dapat mengambil keputusan dan memantau kondisi laporan dengan cepat, terutama saat dipakai di perangkat mobile.

10. Manajemen Siswa

Bagaimana data siswa dikelola?

  • Admin dapat menghapus siswa yang tidak valid
  • Admin dapat mencari data siswa berdasarkan nama atau nomor handphone
  • Admin dapat melihat detail siswa beserta riwayat laporan

12. Tantangan & Solusi

Tantangan yang dihadapi dan cara mengatasinya

Tantangan

  • Login harus memakai nomor handphone
  • Akses dari HP perlu URL lokal
  • Dashboard harus cepat saat dibuka di ponsel

Solusi

  • Menggunakan phone_number sebagai credential utama
  • Mengatur APP_URL sesuai IP perangkat
  • Mengoptimasi query dan asset halaman agar lebih ringan
